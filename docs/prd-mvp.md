## 1. 产品目标

**一句话定位**：一个能「一键写小说」的、跨平台、完全离线、零调用外部 API 的写作工具。

**概述**：墨匠是一款面向中文网文作者的完全离线、跨平台一键小说写作工具。它通过「模板 + 规则 + 语料库」的本地生成引擎，让用户在输入题材、基调、目标字数与可选设定后，一键产出连贯的章节正文；同时提供大纲、角色、世界观等结构化创作能力与正文的联动，帮助作者跑通从「卡文」到「成稿」的完整闭环。全部生成、存储、导出均在本地完成，不依赖任何网络与云端，保障隐私与零成本。

**核心目标（3-5 条）**：
1. **离线优先**：所有生成、存储、导出在本地完成，零外部请求，保障隐私与可用性。
2. **一键成稿闭环**：输入设定 → 一键生成章节正文 → 编辑 → 保存 → 导出，MVP 跑通完整创作闭环。
3. **结构化创作联动**：大纲 / 角色 / 世界观等元数据能被生成引擎读取并影响正文，做到「设定即生成」。
4. **中文网文向优化**：句式模板、情节骨架、节奏控制贴合中文网文（爽点、钩子、章末悬念）。
5. **可控可改**：生成结果可重生成、可局部改写、可调节随机度 / 风格，作者始终掌握主导权。

## 5. 差异化策略（「超越市场」的具体打法）

不空喊口号，落地为以下**可验证差异点**：

1. **离线隐私优先**：与多数「AI 写作」依赖云端 API 不同，墨匠零网络请求，草稿 / 设定永不离开设备——对隐私敏感作者与涉密创作是硬差异。
2. **结构化创作联动**：市场工具多为「输入框 → 生成」，墨匠让大纲 / 角色 / 世界观成为生成的输入（设定即生成），生成内容自动贴合已建设定，减少前后矛盾。
3. **零成本**：无 API 订阅费、无按字计费，一次获取长期使用，对长更作者成本优势明显。
4. **可控可改**：非黑盒大模型，作者可调随机度、重生成、局部改写、编辑模板语料，创作主导权在用户。
5. **中文网文向优化**：句式模板与情节骨架针对中文网文节奏（章末钩子、爽点密度、对话占比）调校，而非通用英文语料。
6. **跨端一致**：同一套本地项目文件在 Windows / Android / iOS 间可迁移（本地文件交换），创作不绑设备。
