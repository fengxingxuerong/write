# 墨匠网页工作台（首版）

打开 `D:\novel-writer\web\index.html` 即可使用。必须保留同目录的 `app.js`、`ai.js`。

## 已实现

- 作品新建、搜索、归档、编辑信息与确认删除。
- 章节新增、标题/大纲/正文编辑、排序、确认删除、自动本机保存、刷新恢复。
- 角色、世界观条目的增删改；章节查找替换、阅读、卷纲、字号、专注模式、番茄钟。
- TXT、Markdown、JSON 导出与 JSON 导入。网页 JSON 并不保证可直接放回 Flutter 项目目录；请保留桌面原文件。
- 配置真实 OpenAI 兼容或 Ollama 服务：连接测试、生成、续写、全文修改、校对建议、取消请求。结果先预览，再追加或替换，防止误写其他章节。
- 主题切换：顶栏「🌓 主题」按钮在浅色 / 深色间切换；未手动选择时跟随系统 `prefers-color-scheme`，手动偏好持久化到独立 localStorage 键（与作品数据隔离）。
- **关系引导图（`relations.html`，可独立打开）**：梳理人物关系、情节线与伏笔的可视化画布。三类节点（角色 / 情节 / 伏笔，伏笔区分埋设中与已回收）、带说明的有向连线；拖动节点、拖动空白平移、滚轮缩放、纯 JS 力导向「自动布局」；节点与连线的增删改、按类型过滤、选中详情。工作台头部「关系图」按钮会新标签页进入并自动把当前作品的角色、世界观（含伏笔账本）、章节大纲播种成节点，角色「关系」文本中出现其他角色名的片段会自动生成连线；也可从「导入」选择桌面端项目 JSON（单本或备份数组均可，按「类型 + 名称」去重合并）。数据存独立 localStorage 键 `inksmith.relations.v1`（与作品数据隔离），支持导出 JSON 备份与导出 SVG 图片。

## 数据与连接限制

数据只存在当前浏览器/站点中，清理浏览器会丢失。请定期备份。多标签页冲突会暂停写入；保存失败时请先导出。

模型配置和密钥只保存在本页内存，刷新后清除。只有点击测试或在同意发送后点击 AI 操作才发起请求。云端请求可能产生费用；浏览器直连需要服务正确配置 CORS。不要关闭浏览器安全设置。HTTPS 端点或本机 HTTP 端点均支持。

未接入真实付费模型验收：目前使用受控响应验证请求模块，不保证任意服务商兼容。当前为非流式请求。

还未移植：五角色长篇流水线、EPUB/DOCX、封面、全书质检、敏感词库、历史版本与存稿箱等。原宣传页中的这些介绍并不代表网页版已实现。
