    THE COMPLETE WRITING TOOLKIT

    从书架到成书，创作所需尽在这里

    依据当前 Flutter 源码整理。下方为软件功能介绍，不是网页中的可执行入口。

    全部功能分组

    01 / LIBRARY

    作品书架与项目管理

    • 新建作品：书名、题材、基调
    • 标题搜索、排序；全部 / 写作中 / 已归档筛选
    • 作品重命名、删除、归档与取消归档
    • 卡片展示章数、字数、更新时间
    • 单项目 JSON 文件存储，拷贝文件迁移
    • 明亮 / 深色 / 跟随系统主题

    软件入口：作品列表

    02 / EDITOR

    沉浸编辑与写作效率

    • 三栏工作区，侧栏切换与专注模式
    • 自动保存、失焦保存与手动保存
    • 实时字数、目标进度、段落与句子统计、今日写作量、平均句长
    • 字号、行距与衬线字体切换
    • 章内查找替换、匹配跳转、全部替换；全书搜索定位
    • 25 分钟番茄钟与键盘快捷操作

    软件入口：工作区 → 编辑器

    03 / STRUCTURE

    章节、大纲与创作留底

    • 章节新增、删除、标题编辑、上下移动与拖拽排序
    • 章节大纲编辑；卷纲总览、复制与回到章节编辑
    • 按空行块拆分长章节并重排
    • 存稿箱：暂存、预览、转为正式章节、删除
    • 历史版本快照查看与恢复
    • 节拍板：场景结构、编辑节拍、切换骨架、按骨架重写

    软件入口：章节栏 / 编辑器更多 / 工具箱

    04 / WORLD BUILDING

    角色档案与世界书

    • 角色姓名、定位、性格、背景、关系与对话风格
    • 角色与世界观设定增删改
    • 世界观分类、标题及设定正文
    • 世界书角色档案与关系网展示
    • 按分类浏览世界观；生成并复制上下文文本
    • 生成时复用已有角色设定；AI 记忆自动提取并积累新信息

    软件入口：右侧设定面板 / 工具箱 → 世界书

    05 / GENERATION

    一键生成与 AI 辅助

    • 离线模板引擎 / LLM 引擎切换
    • 玄幻、都市、科幻、言情、悬疑五种题材
    • 基调、目标字数、随机度、主角与章节大纲
    • 段落结构与文风设置；AI 扩写大纲
    • 1–10 章连写、卷纲分配、承接上文、AI 章节标题
    • 生成进度、取消；编辑器流式续写、选中修改、全文校对及勾选应用

    软件入口：一键生成 / 编辑器 AI 工具

    06 / MODEL CONNECTION

    模型连接与生成设置

    • 提供商、模型名、Base URL、API Key 与温度设置
    • 测试连接、检测本地模型
    • Ollama / llama.cpp 本地服务及兼容云端 API
    • AI 记忆开关与生成偏好保存
    • 模型服务需自行部署或配置；云端调用可能产生费用
    • 本网页不接收密钥、不连接服务、不上传正文

    软件入口：设定面板 → AI 设置

    07 / AI PIPELINE

    五角色长篇流水线

    • 任务创建、列表刷新、查看与删除
    • 目标总字数、章节上限、题材与主角配置
    • 规划官、正文写手、去 AI 味编辑、标题官、一致性审校独立模型配置
    • 润色开关、每五章一致性审校开关
    • 手动运行、停止请求、进度日志、已完成章节断点保存与续跑
    • 简版质检报告；完成任务导入书架、导出 TXT

    软件入口：书架 → AI 流水线

    08 / CONTINUITY

    自动衔接与质量护栏

    • 全书大纲 → 场景拆分 → 正文 → 润色 → 标题
    • 短场景续写、字数不足补写、首尾衔接去重
    • 润色失败或缩减过多时保留原文
    • 章末钩子检查与补写、本地规则质检
    • 五维语义评分、低分重写尝试、跨章状态追踪
    • 伏笔台账与长期未回收提醒；已配置备用链时的模型故障转移

    流水线自动执行；部分参数仅底层配置，非界面开关

    09 / REVIEW

    敏感词检查与全书体检

    • 分类敏感词检查、命中上下文与分类统计
    • 自定义词增删、历史累计命中排行；保存与替换后复查
    • 全书体检：文笔卫生、规则闸门与商业指标
    • 总分卡、章节问题与重新体检
    • 复制定点修指令、导出 TXT 体检报告
    • 检测与评分仅供辅助，不承诺平台过审或准确识别 AI 写作

    软件入口：编辑器检查 / 书架 → 全书体检

    10 / READER

    阅读与排版预览

    • 内置阅读器及章节导航
    • 上一章 / 下一章切换
    • 白色、米黄、夜间三种阅读主题
    • 字号、行距与衬线字体调节
    • 阅读偏好本地持久化

    软件入口：工作区 → 阅读预览

    11 / PUBLISHING

    五种格式与封面生成

    • TXT 纯文本、Markdown、Word DOCX
    • EPUB 电子书、JSON 项目备份
    • TXT / Markdown / Word 附带角色与世界观附录
    • 一键导出全部格式、选择保存路径、记忆导出偏好
    • 本地封面绘制、预览、另存为 PNG
    • 网页写作区仅提供 TXT 导出，其余格式在软件内使用

    软件入口：导出 / 工具箱 → 封面生成

    12 / LOCAL FIRST

    本地数据与运行诊断

    • 项目及应用偏好保存在本机
    • 模板生成、编辑、阅读、导出无需云端推理
    • 崩溃日志查看与隐私说明入口
    • AI 云端请求需网络；本地 AI 需运行模型服务
    • 任务配置可能包含 API Key，请勿随意分享配置文件

    软件入口：书架菜单 / 隐私页面

    进阶脚本、未接入组件与使用边界

    命令行扩展：Python 长篇流水线另有前情文件续写、JSONL 断点恢复、大纲写前审查、读者反馈、收官终审、问题章重写、收尾补章，以及评估卡、终审卡、书名 / 简介 / 标签上架包文件输出。这些属于脚本工具，不是应用已有按钮，也不会自动发布到平台。

    源码组件：写作教练、分支抉择、修订对比和单章质量体检存在独立组件；当前未确认完整的界面调用链，故不作为可用入口宣传。分支弹窗本身不等于自动重写下游剧情。

    真实 AI 流水线：创建任务后仍需手动运行；停止请求不保证即时中断当前模型请求。重新运行会跳过已有章节。达到章节上限或大纲结束也可能完成任务，不保证达到目标字数或质量标准。备用链及部分评分参数属于底层配置。

    连接提醒：流水线角色表单目前没有协议选择器；新配置的默认协议可能与云端地址不匹配，应核实提供商协议和端点，不能只改 URL 就假定连通。AI 内容需人工审阅。

    网页范围：本页为功能全览与独立演示。实际可用的是草稿编辑、本机保存、TXT 导出、功能搜索、模板流水线演示与结果追加；未移植 Flutter 后端，也不会读取桌面软件项目。
